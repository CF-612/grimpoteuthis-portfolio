<h1 align="center">从草图到云端</h1>

<p align="center">烟灰蛸作品集 · 制作过程<br><a href="../README.md">返回仓库首页</a> · <a href="https://grimpoteuthis.pages.dev/">看看完成的网站</a></p>

这个网站从几张手绘示意图开始：先有水流与坠落的开场，再露出人物头图，往下是自我介绍、游戏文件夹、错落的画廊和云下邮箱。

构图、人物和视觉方向由我绘制与确认。AI 生图先用于临时占位，代码在 AI 协助下逐步实现；自己的素材画好后，再替换临时图，继续调整布局、层次和动效。

**原稿与分镜 → AI 占位与早期设计 → 手绘素材接入 → 细节优化 → 检查并上线**

### 从最初的规划开始

我想做的不只是一个投递用的作品目录，也想让它成为自己的游戏与绘画展示空间。规划中明确了用网名“烟灰蛸”作为网站品牌，把游戏项目和视觉作品作为主要内容，再加入自我介绍与联系方式。

**入场设计的灵感来自 [《Persona 3 Reload》（P3R）官网](https://p3re.jp/)**，尤其是它流畅的转场节奏和清新感。我结合自己的角色与世界观重新画了分镜，把开头改为留白文字、从顶部逐股落下的粉色水流，再接坠落人物与动态头图。粉色、奶油黄和浅紫围绕自己的画面展开。

游戏目录逐渐定为错层文件夹；画廊则想做成“群星环抱恒星”，通过移动、缩放和层次变化切换焦点。原始示意图用于表达想法，实际页面继续根据浏览效果调整。

## 04 · 继续调整，直到像自己的页面

这一阶段有多轮来回修改。Astra 重点美化了头图字标、开场水流、自我介绍的信息区、云下邮箱，以及导航、画框和标签等局部细节。我再根据预览效果提出调整：保留满意的构图，修正重影、遮挡、缩放和板块衔接。后面的迭代也继续保留这些修改。

| 部位 | 修改内容 |
| --- | --- |
| 首页 | 缩小人物和字标，露出重影眼睛；调整标题、个人作品集标签与英文句子的排版。 |
| 开场与衔接 | 水流逐股加入、逐渐汇合；纯白人物穿过层云。首页云朵随滚动逐片进入，云形边缘分别适配桌面和手机。 |
| 自我介绍 | 气泡改为粗线条，拆分素材后重新安排遮挡与浮动。 |
| 游戏档案 | 修正文件夹边缘和文字比例；补充作者角色、独立标题、视频、TapTap 图文、策划节选与美术展示。 |
| 画廊 | 保留不平衡构图，加入画框、星饰与标签；缩略图尽量自动居中，预览条改为弧形。作品数量随数据扩展。 |
| 邮箱 | 调整本体透视、左侧开门与信封大小；简化寄信箭头，社交入口改为黄色线框图标。 |

### 水流和第五幕，经过了多轮迭代

从保留的脚本和早期写入记录中，恢复了下面五个可以确认的开场阶段。**v21 的水流已经是新版**；对比旧水流，使用的是更早的实际函数。它们在统一画幅与相同时刻重新渲染，便于看清变化。

| 阶段 | 水流与转场的变化 |
| --- | --- |
| 早期实现 | 两股细流先落下，再用一整片波浪色幕铺满；第五幕是简化的白色裙摆轮廓。 |
| 细流与布褶修订 | 改为五股错时下落的水流，再接汇合色幕；白色裙摆按纵向移动，增加布褶与轮廓。 |
| v11 · 手绘素材接入 | 水流沿用上一轮；第五幕换成更细致的布料 SVG，人物头图接入自己的手绘素材。 |
| v20 · Astra 重做水流 | 水流自身加速下落、沿路径扩宽并相互汇合，自然覆盖屏幕；白色布幕连续揭开头图，约 3.9 秒。 |
| v21 · Astra 优化第五幕 | 延续 v20 水流，加入自己绘制的纯白坠落人物、淡紫层云和柔和阴影，整段放缓到约 4.4 秒。 |

![恢复的三种水流实现，慢速并排播放](process/water-generations.gif)

动图以两倍慢速播放三种恢复出的水流逻辑，从少量细流到铺满屏幕。下面的静帧取相同的四个时刻。

![旧水流到 v20 的同一时刻对照](process/water-generations.webp)

![白色裙摆到纯白人物与层云的五阶段对照](process/pass-generations.webp)

## 05 · 检查，压缩，再上线

![完成后的首页](preview-home.webp)

- 画作分别准备缩略图、舞台展示图和完整尺寸 WebP，保留原始绘画文件。
- 检查六个游戏详情页、图片解码、演示视频、返回导航与作者角色。
- 在桌面和手机模拟尺寸检查布局、大图弹层与入场动画。
- 代码使用 MIT，绘画与展示素材保留相应版权。
- 源码发布到 GitHub，网站通过 Cloudflare Pages 上线。

现在可以在 [grimpoteuthis.pages.dev](https://grimpoteuthis.pages.dev/) 查看网站。后续新画作和新项目会继续加进来。
