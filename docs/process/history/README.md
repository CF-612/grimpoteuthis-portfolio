# 恢复的早期开场代码

为记录制作过程，将已清理备份中的部分实现从仍保留的修订脚本和代码写入记录恢复到这里。恢复过程只提取文件内容与明确的代码修改，没有运行历史清理或发布命令，也没有覆盖当前网站。

| 文件 | 阶段与来源 |
| --- | --- |
| `intro-initial.js` | 2026-09-30 首次新增 `intro.js` 的完整文件内容。 |
| `water-initial.js` | 从上述文件提取原始水流与裙摆函数，增加独立导出接口供对照渲染。 |
| `water-five-streams.js` | 2026-09-30 保留的 `repair-intro.py` 中，五股细流与纵向布褶函数的原始内容。 |
| `water-v11.js` | 水流沿用修订版，裙摆函数恢复自 2026-10-01 v11 素材替换的写入记录；引用仓库现存 `design/assets/skirt-pass-v11.svg`。 |
| `intro-flow-v20.js` | 2026-10-02 Astra 新增文件及随后屏幕比例修订后的几何逻辑，时长 3.9 秒。 |
| `v20-intro.js`、`v20-intro.css` | 同一轮 Astra 新增的动画渲染与样式文件，保留当时的内容。 |

对照图使用统一画幅与时间采样；旧几何保持原始参数。旧轮廓图使用单独的粉色背景，v20/v21 采用各自的动画渲染器。字体与展示排版使用当前环境，图片是恢复后的局部重渲染，不能代替原始全站截图。

这些文件是历史材料。当前网站由 `design/intro-flow.js`、`design/intro.js` 和 `design/intro.css` 构建；这里的脚本不会加入发布包。旧脚本的素材路径以当时网站根目录为基准，单独运行需要相应素材和页面结构。
